## DownAccess 0.1.14

### New

- **Download history (Ctrl+H).** A new window, available from the Downloads menu, keeps track of your downloads (both successful and failed). For each entry, you can open the file, open its folder in Explorer, copy the original URL, or re-download it.

- **Drag and drop URLs.** You can now drag any text containing one or more URLs directly onto the main window. The Add dialog opens pre-filled so you can confirm the format.

- **Import a URL list.** The File menu offers "Import URL list" to load a text file with one URL per line — ideal for adding many downloads at once.

- **Download speed limiter.** In Preferences → Network, you can pick a limit (256 KB/s to 10 MB/s) or leave it unlimited — useful to avoid saturating your connection.

- **Subtitle mode.** In Preferences → Subtitles, choose how subtitles are saved: separate file (.srt next to the video), embedded in the container (toggleable track in the player), or burned into the picture (encoded into the video, slower).

- **Per-download subtitles.** The Add URL dialog now offers a "Download subtitles with this media" checkbox, and a "Subtitles only" format that fetches just the subtitles without the video.

- **GitHub project link** in the Help menu.

### Improvements

- **Clearer YouTube search.** Results now include a "Type" column (Video, Playlist, Channel). Individual videos appear first in the list.

- **Smarter preview.** Trying to preview a channel or playlist now shows a clear message instead of an empty window.

- **Warning before a large download.** If you check a channel or a complete playlist in search results, a confirmation reminds you it may take time and disk space. You can pick "Don't show again" to silence the warning and re-enable it later from preferences.

- **Renamed: "Default format".** The preference previously called "Default post-processing" is now "Default format", which is clearer.

### Note

This version is compatible with your existing installation. The update installs automatically and keeps your preferences.

DRM-protected content (Netflix, Disney+, Prime Video, etc.) is not supported.
