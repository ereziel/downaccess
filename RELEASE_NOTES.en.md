## DownAccess 0.1.15

### Improvements

- **Simpler updates.** Updates now install without a wizard — no more "Next → Next → Install". DownAccess updates itself, shows a simple progress bar, then reopens straight into the new version. There's nothing left for you to click.

### Note

This improvement takes effect from the **next** update onward: installing this version still goes through the wizard one last time, and every update after that will be automatic.

This version is compatible with your existing installation and keeps your preferences.

DRM-protected content (Netflix, Disney+, Prime Video, etc.) is not supported.
