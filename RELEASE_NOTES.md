## DownAccess 0.1.14

### Nouveautés

- **Historique des téléchargements (Ctrl+H).** Une nouvelle fenêtre, accessible via le menu Téléchargements, garde la trace de vos téléchargements (réussis et échoués). Pour chaque entrée, vous pouvez ouvrir le fichier, ouvrir le dossier dans l'Explorateur, copier l'URL d'origine ou le re-télécharger.

- **Glisser-déposer d'URLs.** Vous pouvez désormais faire glisser un texte contenant une ou plusieurs URLs directement sur la fenêtre principale. La boîte de dialogue d'ajout s'ouvre pré-remplie pour valider le format.

- **Importer une liste d'URLs.** Le menu Fichier propose « Importer une liste d'URLs » pour charger un fichier texte contenant une URL par ligne, idéal pour ajouter plusieurs téléchargements d'un coup.

- **Limiteur de vitesse de téléchargement.** Dans Préférences → Réseau, vous pouvez choisir une limite (256 Ko/s à 10 Mo/s) ou laisser illimité, utile pour ne pas saturer votre connexion.

- **Mode des sous-titres.** Dans Préférences → Sous-titres, choisissez comment les sous-titres sont enregistrés : fichier séparé (.srt à côté de la vidéo), inclus dans le conteneur (piste désactivable dans le lecteur), ou incrustés dans l'image (gravés dans la vidéo, plus lent).

- **Sous-titres au cas par cas.** La boîte d'ajout d'URL propose maintenant une case « Télécharger les sous-titres avec ce média », et un format « Sous-titres uniquement » qui récupère seulement les sous-titres sans la vidéo.

- **Lien vers la page GitHub** dans le menu Aide.

### Améliorations

- **Recherche YouTube plus claire.** Les résultats affichent désormais une colonne « Type » (Vidéo, Playlist, Chaîne). Les vidéos individuelles apparaissent en premier dans la liste.

- **Aperçu intelligent.** Tenter d'afficher l'aperçu d'une chaîne ou d'une playlist ouvre maintenant un message clair plutôt qu'une fenêtre vide.

- **Avertissement avant un gros téléchargement.** Si vous cochez une chaîne ou une playlist dans les résultats de recherche, une confirmation rappelle que cela peut prendre du temps et de l'espace disque. Vous pouvez choisir « Ne plus afficher » pour faire taire l'avertissement, et le réactiver plus tard depuis les préférences.

- **Renommage : « Format par défaut ».** L'option des préférences anciennement « Post-traitement par défaut » s'appelle maintenant « Format par défaut », plus parlant.

### Note

Cette version reste compatible avec votre installation existante. La mise à jour s'installe automatiquement et conserve vos préférences.

Le contenu protégé par DRM (Netflix, Disney+, Prime Video, etc.) n'est pas pris en charge.
